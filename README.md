# 校园二手交易平台

## 项目简介
本项目是一个面向校园用户的二手交易平台，
支持商品发布、浏览、搜索、收藏、下单、聊天等功能。

## 技术栈
- 后端：Spring Boot
- 前端：Vue 3 + Element Plus
- 数据库：MySQL
- 通信：WebSocket
- 构建工具：Maven

## 主要功能
- 用户注册 / 登录
- 商品发布与管理
- 商品搜索与分类
- 收藏、浏览记录
- 在线聊天
- 管理员后台
